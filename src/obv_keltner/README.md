## 🎯 한눈에 보기

인도 트레이더 니라지 조시(Neeraj Joshi)의 OBV + 켈트너 채널 매매법을 정량 규칙으로 옮겨 검증했습니다. 이익이 나는지 보여주려는 프로젝트가 아니라, **영상의 주장이 데이터로 확인되는지** 검증한 프로젝트입니다.

| 구분 | 거래 수 | 승률 | 평균 R | t값 |
|---|---:|---:|---:|---:|
| 상위 200종목, 영상 규칙 전체 | 1,318 | 44.9% | +0.008 | 0.31 |
| 상위 200종목, OBV 없음 | 2,187 | 52.6% | +0.065 | 2.74 |
| 전종목(2,429), 영상 규칙 전체 | 10,971 | 42.2% | -0.086 | -9.47 |
| 전종목(2,429), OBV 없음 | 18,854 | 46.4% | -0.090 | -11.71 |
| PowerZone Pine 원본(상위 200종목) | 4,407 | 70.4% | -0.023 | -2.43 |

R은 거래 손익을 최초 손절폭으로 나눈 값이며, 편도 0.15% 비용을 차감했습니다.

- **OBV를 더해도 나아지지 않았습니다.** 상위 200종목에서는 OBV가 없는 버전이 가장 좋았고, 전종목에서는 네 변형이 모두 손실이었습니다.
- **시장 국면에 의존했습니다.** 이익은 2025년에 몰려 있고, 파라미터 18개 조합은 표본 내(사실상 2022년 하락장)에서 전부 마이너스였습니다.
- **소형주일수록 나빴습니다.** 대형 +0.008, 중형 -0.014, 소형 -0.126 (영상 규칙 기준).
- **입수한 PowerZone Pine 코드는 영상의 지표와 다릅니다.** 보상/위험 중앙값이 0.34라 손익분기 승률이 74.9%인데 실제 승률은 70.4%였습니다.

> **결론**: 이 구현과 이 데이터에서는 엣지가 확인되지 않았습니다.

## 📐 전략 규칙

영상은 규칙을 눈으로 판단하는 재량 방식이라 수치 기준이 없습니다. 아래 수치 중 상당수는 제가 정한 가정이며, 모두 `P` 딕셔너리의 파라미터로 열어두었습니다.

| 항목 | 내용 |
|---|---|
| 지표 | 켈트너 채널(EMA 20 ± 2 × ATR 10), OBV(양봉이면 거래량을 더하고 음봉이면 뺌) |
| 진입(롱) | 횡보 박스(직전 20봉 고저폭 ≤ 6 ATR)에서 OBV 매집이 확인되고, 종가가 박스 고점과 켈트너 상단을 동시에 돌파하는 장대 양봉. 다음 봉 시가에 진입 |
| 손절 | 박스 저점(최대 3 ATR), OBV가 진입 당시 박스 OBV 저점 이탈 |
| 청산 | 켈트너 중심선 이탈 + OBV가 저점 부근일 때, 하락 다이버전스 익절, 최대 60봉 |
| 분할 익절 | 1R 50%, 2R 25%, 3R 25%, 1차 도달 후 손절선을 본전으로 상향 |

## 🧪 검증 설계

1. 상위 200종목 기본 백테스트
2. OBV 유무 4변형 비교 (OBV 없음, 진입 필터만, 청산만, 전체)
3. 파라미터 격자 18조합의 표본 내/외 비교
4. 유니버스를 전종목 2,429개로 확대
5. 시가총액 구간별 비교 (대형, 중형, 소형)
6. 오픈 소스 PowerZone Pine 코드를 파이썬으로 포팅해 같은 방식으로 검증

## 🚀 실행 방법

```bash
conda activate ta_env
python -m pip install pandas numpy matplotlib sqlalchemy pymysql tqdm requests python-dateutil
# 가격을 새로 수집할 때만
python -m pip install yfinance pykrx
```

Spyder에서는 `Tools > Preferences > Python interpreter > Use the following Python interpreter`에서 `ta_env`의 `python.exe`를 선택한 뒤 커널을 재시작합니다.

🔐 DB 비밀번호는 코드에 쓰지 않고 환경변수 `DB_PW`로 읽습니다 (없으면 실행 시 입력창이 뜹니다).

```bash
# Windows 명령 프롬프트 (한 번만 실행 후 Spyder를 완전히 재시작)
setx DB_PW "비밀번호"
```

파일은 `#%%` 셀 단위이며 Spyder에서 `%runcell` 또는 `Shift+Enter`로 실행합니다. 각 셀이 앞 셀의 변수를 쓰므로 0번부터 순서대로 실행합니다.

| 셀 | 내용 |
|---|---|
| 0 | 안내와 설정 (`RUN_DOWNLOAD`, `MARKET`, `N_TICKERS`, `START`) |
| 1 | DB 연결 함수 |
| 2 | 필요 테이블 확인, `RUN_DOWNLOAD = True`면 가격 수집 |
| 3, 4 | 유니버스 선택과 가격 불러오기 |
| 5, 6, 7 | 파라미터, 지표와 신호, 매매 시뮬레이션 함수 |
| 8 | 기본 백테스트 |
| 9 | OBV 유무 비교 |
| 10 | 파라미터 격자와 표본 내/외 분리 |
| 11 | 그래프 |
| 12, 13, 14 | PowerZone Pine 포팅, 기본 결과, 변형 비교 |
| 15 | 시가총액 구간별 비교 |

`RUN_DOWNLOAD = False`일 때 필요한 테이블이 DB에 없으면 어떤 테이블이 없는지 알려주고 `RUN_DOWNLOAD = True`로 바꾸라고 안내합니다. 티커 테이블(`kor_ticker`)은 별도의 데이터 수집 파일로 먼저 만들어야 합니다.

### 🗄️ DB 테이블

| 테이블 | 용도 | 주요 열 |
|---|---|---|
| `kor_ticker` | 종목 목록과 시가총액 | 종목코드, 종목명, 시장구분, 시가총액, 기준일, 종목구분 |
| `kor_price` | 일봉 가격(수정주가) | 날짜, 시가, 고가, 저가, 종가, 거래량, 종목코드 |
| `global_ticker`, `global_price` | 미국 주식용 (선택, `MARKET = 'US'`) | Symbol, Market Cap, country / Date, OHLCV, Adj Close, ticker |

## ⚠️ 한계

- 영상 사례는 5분~1시간 봉이고 이 검증은 일봉입니다.
- 영상의 OBV 판단(레벨 비교, 다이버전스)은 재량이라, 규칙으로 옮기면서 손실이 생겼을 수 있습니다.
- 박스 판정, 목표가 거리 등 일부 수치는 가정입니다. 영상의 OBV 파워존 지표 코드는 비공개입니다.
- 유니버스가 현재 상장 종목 기준이라 생존편향이 있습니다.
- 데이터가 약 5년뿐이라 하락장 1번, 상승장 1번만 포함합니다.
- 비용(편도 0.15%)은 임의 가정이며 소형주에는 낮습니다.
- t값은 거래가 독립이라고 가정하므로 실제보다 큽니다. 자본 제약과 동시 보유 수는 반영하지 않았습니다.
- Pine 포팅의 체결 가정이 TradingView 전략 테스터와 같은지는 확인하지 못했습니다.
