## 📐 기준 (7가지)

| 기준 | 구현 |
|---|---|
| 적정 규모 | 매출 1,000억 원 이상 (원전의 1억 달러를 환산한 값, 분석자 설정) |
| 유동비율 | 유동자산 / 유동부채 ≥ 2.0 |
| 장기부채 | 비유동부채 ≤ 유동자산 − 유동부채 |
| 이익 안정성 | 연속 흑자 (실제 버전 10년, 변형 버전 4년) |
| 이익 성장 | 순이익 1/3 이상 증가 (주당이익 대신 순이익) |
| PER | 3년 평균 순이익 기준 PER ≤ 15 |
| PBR | PER × PBR ≤ 22.5 |

배당 20년 연속 조건은 과거 배당 데이터가 없어 적용하지 않았습니다.

## 🧪 백테스트 방식

| 구분 | 내용 |
|---|---|
| 정기(A) | 매년 4월 1일 이후 첫 거래일에 통과 종목을 동일가중으로 매수, 1년 보유 |
| 신호(B) | 재무 조건 통과 종목이 매수 상한가(시가총액 ≤ min(15 × 3년 평균 순이익, √(22.5 × 3년 평균 순이익 × 자본총계))) 아래로 내려온 날 매수, +50%에서 청산 (분석자 설정) |
| 벤치마크 | 전종목 동일가중 (코스피 지수가 아님) |
| 비용 | 왕복 0.3% |
| 재무 시차 | 결산 후 90일 뒤에 재무를 알 수 있다고 가정 |

## 🚀 실행 방법

```bash
conda activate ta_env
```

1. `kr_collect_core.py` → `kr_dart_long.py` → `kr_delisted.py` 순서로 실행해 MySQL(`stock_db`)에 데이터를 넣습니다. 이미 데이터가 있으면 건너뜁니다.
2. `graham_screen_backtest.py`를 `#%%` 셀 단위로 실행합니다 (Spyder).

🔐 DB 비밀번호는 환경변수 `DB_PW`로 읽습니다. 코드에 직접 쓰지 않습니다.
