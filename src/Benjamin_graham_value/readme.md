\# 그레이엄 방어적 투자자 기준의 한국 시장 적용



벤저민 그레이엄의 방어적 투자자 기준을 한국 상장 종목에 적용해 종목을 고르고, 과거 시점마다 같은 규칙으로 샀다면 성과가 어땠는지 백테스트했다. 전체 분석은 \[보고서](../../reports/graham\_report.pdf)에 있다.



\## 분석 대상

\- 현재 상장 보통주 2,532종목 + 2015년 이후 상장폐지 424종목 (생존편향 완화)

\- 이 중 연간 재무(2013\~2025 회계연도, OpenDART)를 확보한 2,320종목

\- 주가: 네이버 수정주가, 2015-01-02 \~ 2026-10-16



\## 기준 (7가지)

| 기준 | 구현 |

|---|---|

| 적정 규모 | 매출 1,000억원 이상 (원전의 미화 1억 달러를 환산한 값, 분석자 설정) |

| 유동비율 | 유동자산 / 유동부채 ≥ 2.0 |

| 장기부채 | 비유동부채 ≤ 유동자산 − 유동부채 |

| 이익 안정성 | 연속 흑자 (실제 버전 10년, 변형 버전 4년) |

| 이익 성장 | 순이익 1/3 이상 증가 (주당이익 대신 순이익) |

| PER | 3년 평균 순이익 기준 PER ≤ 15 |

| PBR | PER × PBR ≤ 22.5 |



배당 20년 연속 조건은 과거 배당 데이터가 없어 적용하지 않았다.



\## 두 가지 버전

\- \*\*실제 버전\*\*: 10년 연속 흑자와 10년 성장을 요구한다. 재무가 2013년부터라 백테스트가 2023-04부터 3.5년, 리밸런싱 4회로 짧다.

\- \*\*변형 버전\*\*: 일정 수 이상의 종목을 고르고 더 긴 기간을 검증하려고 흑자·성장 요구 기간을 4년으로 줄였다. 2017-04부터 9.5년, 리밸런싱 10회.



\## 백테스트 방식

\- 정기(A): 매년 4월 1일 이후 첫 거래일에 통과 종목을 동일가중으로 사서 1년 보유

\- 신호(B): 재무 조건을 통과한 종목이 매수 상한가(시가총액 ≤ min(15 × 3년 평균 순이익, √(22.5 × 3년 평균 순이익 × 자본총계)) 아래로 내려온 날 매수, +50%에서 청산(분석자 설정)

\- 벤치마크: 전종목 동일가중 (코스피 지수가 아님)

\- 거래비용 0.3% 왕복, 결산 후 90일 뒤에 재무를 알 수 있다고 가정



\## 결과

| | 정기(A) | 신호(B) | 벤치마크 |

|---|---|---|---|

| 변형 버전 CAGR (9.5년) | 3.1% | 3.1% | 6.1% |

| 실제 버전 CAGR (3.5년) | 5.6% | 5.6% | 3.8% |



\- 변형 버전은 기준값 6가지 조합을 바꿔도 모두 벤치마크에 못 미쳤다.

\- 실제 버전의 우위는 2025\~2026년에만 나타났고, 2025년을 빼면 격차가 오히려 벌어졌다.

\- 현재(2026-10-16) 7가지 기준을 모두 통과한 종목: 실제 버전 67개, 변형 버전 106개

\## 한계

\- 표본 기간이 짧고(변형 9.5년, 실제 3.5년) 통계적 검정이 아니다.

\- 시가총액은 현재 주식수 × 과거 수정주가로 근사했다.

\- 연결 순이익(비지배지분 포함) 기준이다. 지배주주 기준 점검은 현재 시점 스크리닝에서만 했다.

\- 12월 결산 법인만 분석했고, 일부 기준값은 분석자 설정이다.

\- 폐지 종목 종가가 수정주가인지는 확인하지 못했다.



\## 실행

먼저 `data\_pipeline/`의 `kr\_collect\_core.py` → `kr\_dart\_long.py` → `kr\_delisted.py`를 순서대로 실행해 MySQL(`stock\_db`)에 데이터를 넣는다. 이미 데이터가 있으면 건너뛴다. 그다음 `graham\_screen\_backtest.py`를 `#%%` 셀 단위로 실행한다 (Spyder, conda 환경 `ta\_env`).



DB 비밀번호는 환경변수 `DB\_PW`로 읽는다. 코드에 직접 쓰지 않는다.
