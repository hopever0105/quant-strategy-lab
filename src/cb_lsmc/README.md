# 🔁 전환사채(CB) LSMC 평가

**국내 전환사채의 미국형 전환권·조기상환청구권(풋)·리픽싱을 모두 넣은 가상의 3년 만기 CB를 LSMC(Least Squares Monte Carlo)로 평가했습니다. CB 가치는 액면 100 기준 134.13이고, 이 가운데 리픽싱이 11.31을 차지합니다. 리픽싱 없는 경우를 이항트리로 풀어 대조해 보니, 회귀 기저에 따라 LSMC 값이 0.72 낮게 치우쳤고 기저를 바꾸자 차이가 0.18로 줄었습니다.**

> 포트폴리오용 개인 분석입니다. 가상의 예시 상품이며 실제 발행 CB의 가격이나 투자 권유가 아닙니다.

## 왜 LSMC인가

리픽싱이 있으면 전환가액이 지나온 주가 경로에 따라 달라져 이항트리 노드가 재결합하지 않습니다. 그래서 경로를 시뮬레이션하고, 행사 시점마다 '계속 보유 가치'를 회귀로 추정해 전환·풋 행사 여부를 정했습니다.

## 상품 (가상의 예시)

| 항목 | 조건 |
|---|---|
| 기초주식 / 최초 전환가액 | JYP Ent.(035900), 2026-10-29 종가 38,600원 (할증 0%) |
| 만기 / 표면이자 / 만기보장수익률 | 3년 / 0% / 2% (3개월 복리, 만기상환 106.17) |
| 전환 | 1년 후 ~ 만기 1개월 전, 매주 |
| 조기상환청구권 | 1.5년 후 3개월마다, 조기상환수익률 2% |
| 리픽싱 | 3개월마다 주가가 전환가액보다 낮으면 하향, 하한 70% |

## 핵심 결과 (평가 기준일 2026-10-29)

| 구성 | 가치 (액면 100) |
|---|---:|
| 순수 채권 (만기상환만) | 92.90 |
| + 전환권 | +29.05 |
| + 조기상환청구권 | +0.87 |
| + 리픽싱 | +11.31 |
| **CB 가치** | **134.13** (±0.07) |

| 엔진 검증 | 기준값 | LSMC / MC |
|---|---:|---:|
| 만기에만 전환하는 CB | 해석해 121.27 / 트리 121.27 | 121.28 (±0.14) |
| 주식 버뮤단 풋 (1년) | 트리 0.1669 | 0.1668 |
| 리픽싱 없는 CB: 다항식 기저 | 트리 122.88 | 122.16 |
| 리픽싱 없는 CB: 해석해 기저 | 트리 122.88 | 122.70 (±0.09) |

- 시나리오: 신용스프레드 BBB- → 128.38, 최근 1년 변동성 → 136.90
- 민감도: 주가 +1% → +0.50, 변동성 +1%p → +0.70, 스프레드 +50bp → −0.55, 배당수익률 +1%p → −1.45

자세한 내용은 `전환사채_LSMC_평가_보고서.docx`(4쪽)를 보세요.

## 모형

- 위험중립 GBM, 주 단위 정확 이산화, 대조변수
- 신용위험: Tsiveriotis-Fernandes. 전환으로 받는 몫은 무위험금리, 현금 상환분(만기·풋)은 무위험금리 + 신용스프레드로 할인
- 회귀 기저: 패리티 다항식 + 리픽싱 상태 + 같은 상태의 유럽형 CB 해석해
- 회귀계수는 훈련 경로 10만 개, 가격은 다른 난수 경로 20만 개로 산출(out-of-sample)

## 실행 방법

```bash
pip install numpy scipy pandas matplotlib requests python-docx
python data.py          # 시장데이터 → data/ (저장소에는 올리지 않음)
python run.py           # 검증·가치 분해·시나리오·민감도 → results/ (약 8분)
python build_report.py  # 보고서 docx (Windows Word가 있으면 pdf도)
```

## 파일 구성

| 파일 | 내용 |
|---|---|
| `core.py` | LSMC 엔진(TF 할인, 리픽싱, 회귀 기저), 해석해, TF 이항트리, 버뮤단 풋 검증 |
| `data.py` | 주가·금리·스프레드 수집 |
| `run.py` | 파라미터 → 검증 → 가치 분해 → 시나리오 → 민감도 → 그림 |
| `build_report.py` | 보고서 생성 |
| `results/` | `results.json`, 그림(주가별 가치·수렴·민감도·표본 경로) |

## 한계

- 상수 과거 변동성, 등급 평균 신용스프레드를 썼습니다.
