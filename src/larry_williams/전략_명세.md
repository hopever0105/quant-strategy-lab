# 래리 윌리엄스 검증 - 합의된 전략 명세 (2026-11-12 확정)

> 이 파일이 /quant 1단계 "이해 확인 → OK"를 대신한다. 사용자가 새 채팅에서 "래리 해줘"라고 하면 이 명세대로 묻지 않고 2단계(구현·백테스트)부터 바로 시작한다.
> 실제 주문·매매 코드 없음. 포트폴리오(quant-strategy-lab)용.

## 0. 공통 원칙

- **검증 방식**: 시간 순서로 나눈다(무작위 8:2 금지).
  - 학습 2000~2014 / 검증 2015~2019 / 테스트 2020-01~2026-11 (테스트는 마지막에 **한 번만**)
  - 보조로 연 단위 워크포워드(확장 창): 매년 그해 이전 데이터로만 파라미터 선택 → 그해 성과만 이어 붙임
- **파라미터 선택**: 후보 격자는 아래에 고정(사후 추가 금지). 학습 구간 샤프 기준으로 고르고 검증 구간에서 확인. **시도한 조합 수를 보고서에 적는다.**
- **유의성**: 겹치는 표본은 Newey-West t값. 알파 t값, 테스트 구간 성과, 거래비용 2배 결과를 함께 보고.
- **미래정보 금지**: COT는 기준일(화) +6일(다음 주 월요일)부터 사용. 연간 재무는 다음 해 4월부터, 분기 재무는 공시일 이후.
- **생존편향**: 종목 전략은 상장폐지 포함(kor_price_delisted, kor_delisted).
- **KRX**: 최근 연속 실패로 자동 중지가 반복됐음. KRX가 필요하면 krx_guard install() 후, 남은 건수 확인, 실패 시 즉시 멈추고 보고. 가능하면 stock_db·FDR(KRX 외 출처)만 쓴다.
- **연속선물**: 야후 연속선물(CL=F 등)은 만기 교체 시 가격이 끊기고 2020-04 마이너스 유가가 있음 → 수익률 계산은 만기 교체 보정 또는 ETF(USO 등)·현물지수로 대체. 상관 분석은 로그수익률로.

## 1. 매크로 (① - 시장 간 관계·심리)

| 항목 | 규칙 | 후보 격자 (학습 구간에서 선택) |
|---|---|---|
| COT 상업자 지수 | (상업자 순포지션 − N주 최저)/(N주 최고 − N주 최저)×100, 래리 공식 그대로 | N ∈ {26, 156}주 / 극단 기준 ∈ {20/80, 25/75} / **시장별로 따로 선택** (S&P500, 30년 국채, 금, 원유) |
| 채권 → 주식 선행 | 채권 가격이 n일 이동평균 위면 주식 매수만 허용 | n ∈ {10, 20, 50, 200}일 (미국 30년 국채 선물 또는 TLT, 국내는 국고채 금리 역수/cd91_rate 보조) |
| 유가 → 코스피 선행 | WTI 수익률과 코스피 수익률의 **시차 상관** 계산 → 학습 구간에서 최적 시차 선택 → 그 시차의 유가 추세 신호로 코스피 매수/현금 | 시차 ∈ {20, 30, 40, ..., 130}거래일(약 1~6개월), 유가 신호 = 시차만큼 앞당긴 유가의 m일 수익률 > 0, m ∈ {20, 60} |
| 패닉 지표 | 코스피 고점 대비 급락 시 매수 | 낙폭 ∈ {10%, 15%, 20%} (20일 내), 보유 ∈ {60, 120}거래일 |

- 업종별 확장(탐색용): 유가 선행 효과를 정유·화학·항공·운송 업종지수에도 계산 (원가·매출이 유가에 직접 묶여 있어 경제적 이유가 있음). 시기(TDM)·지표·패턴은 업종별로 나누지 않는다(시장 전체 자금 흐름 현상이고, 변동성 돌파·손절폭 기준 포지션은 이미 변동성으로 정규화돼 있음).
- 래리 주장 검증 포인트: 학습에서 뽑힌 시차가 **1.5~6개월 안에 들어오는지**, 테스트에서도 유지되는지.
- 이미 받은 COT 데이터: `quant/cache/cftc/cot_*.csv` (CFTC 공식 API), 시험 코드 `quant/strategies/larry_cot/probe.py`, 결과 `larry_cot/results/cot_probe.csv`.
  (같은 폴더의 `deacot*.zip` 11개는 CFTC 차단 페이지(HTML) → 사용자 허락 후 삭제)

## 2. 단기 매매 시스템 (② - 깔때기, 코스피200)

순서: 조건(1단계) → 시기(2) → 상태(4) → 방아쇠(5) → 청산 → 포지션 크기(6). **조합은 하나로 고정**, 조건을 하나씩 뺀 버전은 강건성 검증으로만.

| 단계 | 규칙 | 후보 격자 |
|---|---|---|
| 조건 | ①에서 학습 구간에 선택된 COT(S&P500)·채권 필터 | ①의 선택값 그대로 |
| 시기 - TDM | 책의 S&P500 기준(월말 마지막 거래일 ~ 다음 달 초 몇 거래일)을 그대로 적용 + 코스피 자체 TDM(학습 구간 추정)도 비교 | 월초 거래일 수 ∈ {3, 4, 5} |
| 시기 - 선거 주기 | 선거일 전후 한 달 구간 | 미국 중간선거·대선, 한국 대선·총선 각각 ±1개월 |
| 상태 | Williams %R 10일, −80 아래에서 위로 올라올 때 (책 수치 그대로) | 고정 |
| 방아쇠 | Oops!(시가 < 전일 저가 → 전일 저가 회복 시 매수), 변동성 돌파(시가 + k×전일 변동폭) | k ∈ {0.4, 0.5, 0.6, 0.8, 1.0} |
| 청산 | Bailout(처음 수익 난 시가) + 시간 청산 + 손절 | 시간 청산 ∈ {3, 5, 10}일, 손절 = 진입가 − 전일 변동폭×{1, 2} |
| 포지션 | 계약(주식) 수 = 잔고 × 위험% ÷ 손절폭 | 위험% ∈ {1, 2, 3}% (학습 MDD 30% 이내에서 최대 샤프) |

- 데이터: 코스피200 일봉(시가·고가·저가·종가 필요). 출처는 stock_db/FDR 먼저 확인(KRX 외 출처), 없으면 KODEX 200(069500) 일봉으로 대체.
- 거래비용: 편도 0.015% + 슬리피지 0.05% (ETF 대체 시), 2배 민감도.

## 3. 우량주 필터 (③ - 종목 선정, 국내 전 종목)

래리는 기준 숫자를 공개하지 않음 → **통상 기준(절대값)과 분위수 기준 두 시나리오**를 학습 구간에서 비교.

| 항목 | 통상 기준 시나리오 | 분위수 시나리오 |
|---|---|---|
| 부채비율(부채/자본) | ≤ 100% (국내 관행: 100% 이하 우량, 200% 초과 주의) | 하위 30% |
| PER | 0 < PER ≤ 10 | 양(+)의 PER 중 하위 30% |
| PSR | ≤ 1.0 (켄 피셔 기준 0.75 변형 포함: {0.75, 1.0}) | 하위 30% |
| 세금 납부 | 법인세비용 > 0 **그리고** 현금흐름표 법인세 납부 > 0, 유효세율 5~40% | 동일 |

- **유니버스**: 코스피(타임폴리오 대회 종목 942개 = 2026-10-05 기준 코스피 전 종목). 단, 그 목록은 현재 생존 종목이라 과거 백테스트에 그대로 쓰면 생존편향 → 각 시점에 코스피에 상장돼 있던 종목(상장폐지 포함)을 kor_ticker·kor_price_delisted로 재구성. 대회 목록은 최근 구간 점검용으로만.
- **기준 강도 시나리오(사전 등록, 결과 보고 나서 추가 금지)** - 임의 숫자 대신 **실제 분포**로 정한다:
  - 통상 기준(위 표: 부채 100%, PER 10, PSR 1)
  - 분포 기준: 학습 구간(2000~2014) 코스피 비금융 종목의 부채·PER·PSR 분포에서 하위 30% / 50% / 70% 지점을 기준선으로 (타이트 / 중간 / 넓게)
  - 업종 상대: 같은 업종 안에서 하위 30%. **업종 분류는 타임폴리오 대회 파일의 '업종명' 열을 쓴다** (`04_포트폴리오_작업원본/02_투자대회/타임폴리오/data_1331_20261005.csv`, cp949, 열: 종목코드·종목명·시장구분·업종명·종가·대비·등락률·시가총액). 대회 목록에 없는 과거·상장폐지 종목은 kor_sector로 보완하고, 보완한 종목 수를 보고서에 적는다 → 업종마다 재무 구조가 달라서(건설·유틸리티는 부채가 높고, 소프트웨어는 PSR이 높음)
  - CRSP 가치 점수: 래리가 추천한 Vanguard Mid-Cap Value가 따르는 CRSP 지수의 가치 지표(장부가/가격, 이익/가격, 배당/가격, 매출/가격)를 합성한 점수 상위 30% (지표 목록은 CRSP 방법서로 확인 후 사용)
- 총 시나리오 = (통상 1 + 분포 3 + 업종 1 + CRSP 1) × 진입 2방식 = 12개. 학습 구간에서 고르고 테스트는 한 번.
- 금융업(은행·증권·보험) 제외(부채비율 의미 없음), 시가총액 하위 20% 제외(유동성).
- 진입: 필터 통과 + 가격 추세 확인(종가 > 200일 이동평균 또는 %R 과매도 탈출) - 래리의 "조건부 매매". 두 진입 방식 비교.
- 리밸런싱: 연 1회(4월 말, 연간 재무 공시 후) + 분기 재무 버전 비교. 동일가중, 최대 30종목.
- 벤치마크: 코스피, 동일가중 전 종목.
- 데이터: kor_price(+delisted), kor_fs / dart_fs, kor_sector, kor_ticker. 테이블 구조 먼저 확인.
