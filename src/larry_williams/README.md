# 📏 래리 윌리엄스 매매 원칙 검증

**래리 윌리엄스가 말한 원칙 11가지(COT 상업자 지수, 채권·유가 선행, 패닉 매수, 월말·월초, 선거 주기, 깔때기 단기 시스템, 우량주 필터)를 국내·미국 데이터로 하나씩 검증했습니다. 학습 2000~2014 / 검증 2015~2019 / 테스트 2020~2026으로 나누고 미리 정한 후보 390개 안에서만 골랐습니다. 테스트까지 뚜렷하게 유지된 원칙은 없었고, 쓸 만한 것은 수익을 더하는 신호가 아니라 위험을 줄이는 신호(COT 상업자 지수: 최대 낙폭 −55% → −22%)였습니다. 우량주 필터의 초과수익은 171건 중 6건만 빼도 사라졌습니다.**

> 포트폴리오용 개인 분석입니다. 실제 주문·매매 코드는 없으며 투자 권유가 아닙니다.

## 검증 절차

1. **미래 정보 차단**: 신호는 그날 종가까지의 정보로 만들고 다음 날 적용. 미국 자료는 하루 늦게, COT는 기준일 +6일, 연간 재무는 다음 해 4월 말부터
2. **생존편향 제거**: 상장폐지 종목 포함. 2018-07 이후 상장폐지 230종목의 일봉·거래대금·시가총액을 KRX에서 보강, 정리매매 폭락은 실제 손실로 반영. 상장폐지 종목 재무는 OpenDART로 2,748건 보강
3. **과최적화 점검**: 후보 격자 사전 고정(시도 390개), 테스트 한 번만 계산, 연 단위 워크포워드, 조건 하나씩 빼기, 이웃 파라미터
4. **통계**: Newey-West t, 검정력(t=2에 필요한 연수), 12개월 블록 부트스트랩, Benjamini-Hochberg 다중검정 보정, 무작위 포트폴리오·1년 전 지표(플라시보) 대조
5. **우량주 필터 분해**: 리밸런싱 달 분산(12개 시작월), 한 해 빼기, 섹터 배분 vs 종목 선택, 종목별 기여도

## 실행 방법

```bash
pip install finance-datareader pymysql statsmodels scipy python-docx matplotlib
python run.py          # ①②③ 백테스트 → results/
python robust.py       # 약점 보완 분석
python picks.py        # 우량주 필터 종목·기여도
python winners.py      # 급등 vs 하락 종목 지표 비교
python factors.py      # 전체 시장 지표 검증·블록 교차검증
python build_report.py 최종
```

| 파일 | 역할 |
|---|---|
| `data.py` | 시세·재무·COT·금리 로드, 상장폐지 보강 이어 붙이기, 시가총액 |
| `signals.py` | COT 지수, 채권·유가·패닉 신호, %R, 월말·월초, 선거 구간 |
| `backtest.py` | 시기 전략·단기 시스템·종목 포트폴리오 엔진, 성과 지표, Newey-West |
| `quality.py` | 우량주 필터 유니버스·기준·진입 |
| `dart_fill.py`, `krx_fund.py`, `krx_delist.py` | OpenDART·KRX 보강 수집 (이어받기, 실패 1번이면 중지) |
| `run.py`, `robust.py`, `picks.py`, `winners.py`, `factors.py` | 분석 실행 |
| `build_report.py`, `report_sections_extra.py` | 보고서 |

DB 접속 정보·API 키는 코드에 넣지 않습니다(.env). 같은 데이터면 같은 결과가 나옵니다(난수 고정).

## 한계·생존편향 주의

- 코스피200 대신 코스피 지수(직접 거래 불가)를 썼고, KODEX 200으로는 2015년 이후만 확인했습니다.
- 국내 재무가 2013 회계연도부터라 우량주 필터 학습 구간이 2014~2017로 짧습니다.
- 나중에 상장폐지된 종목의 재무 보유율은 보강 뒤에도 약 72%입니다. 2015년 이전 상장폐지 종목 재무는 DART API에 없습니다.
- 2018-07 이후 생존 종목의 시가총액은 주식 수 보간 추정치입니다. 업종 분류는 두 체계가 섞여 있고 과거 종목에도 현재 분류를 붙였습니다.
- 테스트 7년은 효과를 증명하기에 짧습니다(필요 20년 이상). 그래서 전체 기간·구간별 방향·워크포워드를 함께 보고 판정했습니다.
- 미국 개별 종목은 생존 종목만 있어 쓰지 않았습니다.
