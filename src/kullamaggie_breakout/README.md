# 🚀 쿨라마기 EMA 돌파 전략 검증

**크리스티안 쿨라마기의 모멘텀 돌파 매매를 국내 전 종목(2000~2026, 상장폐지 포함) 일봉으로 검증했습니다. 비용을 빼기 전에는 거래당 +0.07R(t 4.6)로 신호 자체의 우위가 있었지만, 연 회전율이 약 26배라 왕복 0.5% 비용이 우위를 거의 다 가져갔습니다(비용 후 +0.006R, t 0.41). 회전율을 줄인 버전도 미리 정한 판정 기준 5개 중 2개를 통과하지 못해 최종 탈락했습니다.**

> 포트폴리오용 개인 분석입니다. 실제 주문·매매 코드는 없으며 투자 권유가 아닙니다.

📄 보고서: [쿨라마기_돌파_검증_보고서.pdf](쿨라마기_돌파_검증_보고서.pdf) · [docx](쿨라마기_돌파_검증_보고서.docx)

## 규칙
- 후보: 63일 수익률 상위 5%이면서 +30% 이상, ADR(20일 평균 고가÷저가−1) ≥ 4%, 종가 > EMA10 > EMA20 > EMA50, 코스피 > EMA20
- 진입: 다음 날 20일 고가를 돌파하면 매수
- 손절: 진입일 저가(진입가와의 거리가 ADR 이하일 때만 진입)
- 청산: 3일째 1/3 매도, 나머지는 종가가 EMA10 아래로 내려가면 정리
- 거래비용 왕복 0.5%

## 핵심 결과

| 항목 | 결과 |
|---|---|
| 비용 전 | 거래당 +0.07R (t 4.6), 연 15.7% |
| 비용 후 | 거래당 +0.006R (t 0.41), 연 0.6% (코스피 6.6%) |
| 비용 2배 | 연 −12.4% |
| 같은 날 같은 후보 중 무작위 종목 대비 | 약 +0.1R (무작위 20회 모두보다 높음) |
| 조건 없이 급등·고변동 종목 매수 | 거래당 −0.115R (t −23.9) |
| 구간별 | 학습(2000~2014) −4.7%, 검증 +7.9%, 테스트 +7.7% (테스트 알파 t 0.53) |
| 성과 집중 | 상위 5% 거래가 이익의 64% |

**회전율 줄인 버전**(상위 2%·횡보 40일, 하루 신규 1종목, 코스피 EMA20 > EMA50): 전체 연 7.3%, 샤프 0.49, 최대 낙폭 −19%, 알파 t 2.2. 그러나 ① 후보 128개를 보정한 Deflated Sharpe 확률 0.06(운으로 기대되는 최고 샤프 0.78 > 실제 0.49), ⑤ 시봉으로 진입일을 확인하면 2023-11~2026-10 거래당 −0.019R(일봉 가정 +0.041R) → **최종 탈락**.

결론: 쿨라마기 조건은 "급등주를 아무 때나 사는 불리함"을 지워 손익분기까지 끌어올리지만, 비용을 내고도 이기는 쪽으로 뒤집지는 못했습니다. 청산은 EMA10이 EMA20보다 나았습니다.

## 실행 방법

```bash
python run.py          # 기본 백테스트·격자·무작위 대조 → results/
python cost_cut.py     # 회전율 줄이기 격자
python final_check.py  # 사전 기준 5개 최종 판정
python build_report.py
```

| 파일 | 역할 |
|---|---|
| `data.py` | 일봉·상장폐지·코스피 로드 |
| `signals.py` | 모멘텀·ADR·EMA 정렬·돌파 신호 |
| `backtest.py` | 진입·손절·부분 매도·청산 엔진, R 단위 성과 |
| `run.py`, `cost_cut.py`, `final_check.py` | 분석 실행 |
| `build_report.py` | 보고서 |

DB 접속 정보는 코드에 넣지 않습니다(.env). 결과 csv는 저장소에 올리지 않습니다.

## 한계·생존편향 주의
- 일봉으로 장중 진입과 당일 저가 손절을 흉내 냈습니다. 진입일 처리 가정을 보수적으로 바꾸면 연 −41.7%까지 나빠져, 최근 구간은 시봉으로 다시 확인했습니다([hourly_youtube](../hourly_youtube)).
- 상장폐지 종목을 포함했지만 정리매매 구간 체결 가능성은 단순화했습니다.
