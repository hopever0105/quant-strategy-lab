# ⏱️ 유튜브 매매법 시봉 재검증

**일봉으로 이미 검증한 유튜브 매매법 3종(로스 MACD·RSI, OBV·켈트너 채널, 하이킨아시)을 같은 규칙·같은 종목으로 60분봉(2023-12~2026-10)에 다시 돌렸습니다. 15개 설정 중 같은 종목·같은 달 무작위 진입보다 뚜렷이 나은 것은 2개뿐이었고, 그 둘도 평균 R이 음수(덜 잃음)였습니다. 시봉으로 바꾸면 거래가 늘고 폭이 작아져 비용 비중이 커졌습니다.**

> 포트폴리오용 개인 분석입니다. 실제 주문·매매 코드는 없으며 투자 권유가 아닙니다.

## 무엇을 확인했나
1. **일봉 vs 시봉**: 같은 규칙을 일봉·시봉으로 돌려 거래 수, 평균 R, t값 비교
2. **무작위 대조**: 같은 종목·같은 달에 아무 때나 들어간 경우와 비교 (상승장 구간이라 기준선은 0이 아니라 무작위 진입)
3. **쿨라마기 진입일 확인**: 일봉에서 가정한 "장중 돌파 → 당일 저가 손절" 순서를 시봉으로 실제 확인

## 핵심 결과

| 항목 | 결과 |
|---|---|
| 시봉 15개 설정 중 무작위보다 뚜렷이 나은 것 | 2개 (둘 다 평균 R 음수) |
| 로스 매매법 1 (시봉) | 거래당 −0.072R (t −10.9) |
| 쿨라마기 진입일 시봉 확인 | 일봉 '봉 방향' 가정에 가까웠고 약 0.05R 더 나쁨 |

결론: 세 매매법 모두 일봉·시봉 어느 쪽에서도 무작위 진입을 이기지 못했고, 시봉으로 바꾸면 더 나빠졌습니다.

## 실행 방법

```bash
python run_h.py           # 일봉·시봉 백테스트, 무작위 대조 → results/
python kullamaggie_h.py   # 쿨라마기 진입일 시봉 확인
python build_report_h.py
```

| 파일 | 역할 |
|---|---|
| `data_h.py` | 일봉·60분봉 로드 (마감 동시호가 보정) |
| `strategies_h.py` | 세 매매법 규칙 (일봉·시봉 공통) |
| `run_h.py`, `kullamaggie_h.py` | 분석 실행 |
| `build_report_h.py` | 보고서 |

## 한계·주의
- 60분봉은 야후 자료라 3년치뿐이고, 14시 봉에 마감 동시호가가 빠져 종가 봉을 붙여 썼습니다.
- 09시 봉의 약 23%가 거래량 0이라 거래량 신호(OBV)는 부정확할 수 있습니다.
- 최근 상장폐지 141종목 중 9개만 시봉이 있어 생존편향이 남아 있습니다.
