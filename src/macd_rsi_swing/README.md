# 📉 MACD·RSI 스윙 전략 백테스트

**MACD 골든크로스(매매법 1)와 RSI 하락 다이버전스 + MACD 재골든크로스(매매법 2)를 한국 주식 27년(2000~2026-10, 상장폐지 종목 포함)에 적용해 검증한 결과, 거래비용 후 우위가 확인되지 않았습니다.**

> 포트폴리오용 검증이며 투자 권유·실매매가 아닙니다. 주문 코드는 없습니다.

## 전략 규칙 (요약)

- **지표:** MACD(12,26,9), RSI(14). 일봉 수정주가, 신호는 종가 기준·체결은 다음 거래일 시가.
- **매매법 1:** MACD 골든크로스 + RSI 50~70이면 진입(RSI<50이면 50 상향 돌파, RSI≥70이면 50 부근 반등까지 보류). 2R에서 절반 익절 후 손절선을 진입가로 올리고, 잔량은 데드크로스·RSI≤50·본전 이탈 시 청산.
- **매매법 2:** 가격 고점은 높아지는데 RSI 고점은 낮아지는 다이버전스 → 눌림(고점의 85% 이상 유지) → MACD 재골든크로스에서 진입. 2R 전량 익절, 도달 전 데드크로스면 전량 매도.
- **손절:** 직전 10일 최저가(손절폭 3~15%만 진입). **포트폴리오:** 거래당 위험 0.5%, 종목당 최대 10%, 동시 20종목.
- **비용·제약:** 수수료·슬리피지 편도 0.115%, 매도세(연도·시장별), 거래정지·상한가 매수 불가, 20일 평균 거래대금 10억원 미만 제외.

## 실행 방법

1. MySQL `stock_db`에 시세를 준비하고 `.env`에 `DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME`을 적습니다(저장소에 올리지 않음). `QUANT_HOME` 환경변수로 `.env`·`cache/`·`logs/` 위치를 지정할 수 있습니다.
2. 데이터: `data_pipeline/`의 `collect_daily.py`(일별), `backfill_history.py`(1999~ KRX 원본), `stitch_history.py`(수정주가 보정·이어붙이기 → `cache/kor_panel.pkl`). KRX 요청은 `krx_guard.py`를 거칩니다.
3. 백테스트: `python run.py` → `results/metrics.json`, `python select_check.py`(종목 선택 기준 점검), `python us_run.py`(미국 참고), `python build_report.py`(보고서·차트).

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `core.py` | 지표, 신호, 거래 시뮬레이션(numba), 비용·세금, 포트폴리오 |
| `run.py` | 3개 전략 + 비용 2배 + 기간 분할 + 파라미터 민감도 + 무작위 진입 대조 |

| `build_report.py` | 결과 표·차트·Word 보고서 생성 |
| `results/` | 지표 json, 차트 png |
