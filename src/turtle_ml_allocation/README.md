# 🐢 다자산 ETF 추세추종(터틀) + 머신러닝 메타 라벨링

**주식·채권·실물·통화 25개 ETF에 터틀 20일 돌파 신호를 쓰고, 신호마다 '20거래일 뒤 수익일 확률'을 머신러닝으로 예측해 비중을 조절했습니다. 1998~2007년으로 학습하고 2008-01~2026-11을 처음 보는 데이터로 검증한 결과, 터틀은 2008·2022년 하락장 손실을 거의 막았지만 머신러닝은 성과를 개선하지 못했습니다. 예측력(AUC 0.516)이 정답을 무작위로 섞어 학습한 '가짜 학습'(평균 0.496)과 구별되지 않았고, 변수를 18개로 늘려도 같았습니다.**

> 포트폴리오용 개인 분석입니다. 실제 주문·매매 코드는 없으며 투자 권유가 아닙니다.

|---|---:|---:|---:|---:|---:|
| 리스크 패리티 (자산군별 위험 균등) | 2.46% | 3.8% | 0.28 | −12.0% | 100% |
| 60/40 (S&P500 + 미국채 7~10년) | 8.26% | 11.1% | 0.64 | −31.4% | 100% |

| 터틀 + ML | 1.79% | 2.9% | 0.14 | −5.6% | 60% |

| 머신러닝 점검 | 실제 | 가짜 학습 20회 |
|---|---:|---:|
| 터틀 신호 AUC (기본 6개 변수, 로지스틱) | 0.516 | 평균 0.496, 최고 0.518 |
| 터틀 신호 AUC (확장 18개 변수, 부스팅) | 0.524 | 평균 0.494, 최고 0.518 |

- 2008년: 터틀 +6.0% / 60/40 −17.7%, 2022년: 터틀 0.0% / 60/40 −16.6%
- 강건성: 채널 10일 샤프 −0.10, 20일 0.14, 55일 0.33 / 거래비용 2배 −0.07 / 1998년에 있던 13개 자산만 쓰면 0.16
- 신호 종류: 월간 200일선 0.44, 12개월 모멘텀 0.35 — 신호를 거르는 것보다 신호와 판단 주기가 성과를 더 크게 바꿨습니다.

자세한 내용은 `터틀_ML_자산배분_보고서.docx`(8쪽)를 보세요.

## 전략 규칙

| 항목 | 내용 |
|---|---|
| 유니버스 | 주식 10(미국 대형·나스닥100·소형, 유럽, 일본, 신흥국, 한국, 중국, 인도, 중남미), 채권 6(미국채 단기·중기·장기, 물가연동채, 투자등급 회사채, 하이일드), 실물 6(금, 은, 원유, 원자재 종합, 농산물, 리츠), 통화 3(달러, 유로, 엔). 결과를 보기 전에 고정 |
| 시점 기준 편입 | 데이터가 252거래일 쌓인 날부터 편입 (1998년 13개 → 2008년 23개 → 2013년 초부터 25개). ETF 상장 전은 같은 자산의 인덱스 펀드로 이어 붙임 |
| 1차 신호 | 종가가 직전 20일 최고 종가를 넘으면 다음 날 종가에 진입, 직전 20일 최저 종가 이탈 또는 진입가 − 2N이면 다음 날 청산 |
| 비중 | 자산군 4개가 위험을 똑같이 나누고, 자산군 안에서는 60일 변동성 역수. 들고 있지 않은 몫은 미 3개월 국채 |
| 2차 모델 | 입력: 200일선 대비 위치, EMA 21·55·89 정배열, RSI(14), 볼린저 밴드폭, VIX, 장단기 금리차. 정답: 진입 후 20거래일 수익 > 0. 로지스틱 회귀 |
| 학습 방식 | 매년 1월 1일에 정답이 이미 확정된 신호만으로 다시 학습 (첫 예측 2008년) |
| ML 비중 | 배수 = 2 × 예측 확률, 0.3 미만이면 진입 안 함, 합계 100% 상한(레버리지 없음) |
| 거래비용 | 바뀐 비중의 0.05% |

## 검증 절차

1. **미래 정보 차단**: 신호는 그날 종가로 판단하고 다음 날 체결, VIX·금리는 하루 늦춰 사용, 정답이 확정되지 않은 최근 20일치 신호는 학습에서 제외
2. **가짜 학습**: 정답을 무작위로 섞어 같은 절차로 20번 학습 → 실제 결과가 이 분포 밖에 있어야 예측력으로 인정
3. **강건성**: 거래비용 2배, 채널 10·55일, 진입 기준 0.4·0.5, 부스팅 모델, 기간 분할, 고정 유니버스, 신호 교체(200일선·12개월 모멘텀)
4. **사후 점검(구분 표기)**: 결과를 본 뒤 확인한 것 — 상대 배수(p ÷ 학습 승률), 정답 = 거래 실제 손익, 변수 확장 18개

## 실행 방법

```bash
pip install finance-datareader scikit-learn statsmodels python-docx matplotlib
python src/turtle_ml_allocation/data.py          # 시세 수집(캐시 저장, 다시 실행하면 이어받기)
python src/turtle_ml_allocation/run.py           # 백테스트·ML·강건성·가짜 학습 (약 2분)
python src/turtle_ml_allocation/build_report.py 최종   # 보고서 docx + 차트
```

| 파일 | 역할 |
|---|---|
| `universe.py` | 자산 목록·자산군·상장 전 대용 |
| `data.py` | 수집, 이어 붙이기, 추적 오차·가격 단절 점검 |
| `signals.py` | 입력 변수, 터틀·200일선·12개월 모멘텀 신호, 거래 목록 |
| `backtest.py` | 위험 균등 비중, 일별 시뮬레이션, 성과 지표·알파 t값(뉴이-웨스트) |
| `ml.py` | 워크포워드 학습, 가짜 학습, 예측력 진단 |
| `run.py` | 전체 실행, `results/` 저장 |

같은 데이터면 같은 결과가 나옵니다(난수 시드 고정).

## 한계

- 달러 기준이며 원화 환율 효과와 세금은 넣지 않았습니다.
- 리스크 패리티를 레버리지 없이 써서 채권·현금성 자산 비중이 높고(채권 55%, 그중 미국채 1~3년 31%) 수익률 수준이 낮습니다. 비교는 샤프·최대 낙폭 위주로 했습니다.
- ETF 목록은 현재 상장된 상품에서 골랐습니다. 자산군을 빠짐없이 넣고 결과 전에 고정해 사후 선택을 줄였지만 완전히 없애지는 못했습니다.
- 회사채·하이일드 대용 펀드는 ETF와 만기·등급 구성이 달라 주간 상관이 0.84·0.83입니다.
- 종가 체결, 고정 비용 0.05% 가정입니다. 위기 때 실제 비용은 더 컸을 수 있습니다.
