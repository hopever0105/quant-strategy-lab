# 🌱 피터 린치 성장주 기준 검증

**피터 린치의 성장주 선별 기준을 국내 전 종목(상장폐지 포함)에 적용했습니다. 기존 7조건(기준 A)은 상위 5종목이 수익의 91%를 차지해, 빼면 연 0.76%로 사라졌습니다. 문헌 기준으로 다시 세운 기준 B는 2017-04~2026-10 연 8.57%로 전 종목 동일가중(6.10%)보다 높았고 비용 5배·시작일 변경에도 우위가 유지됐지만, 월간 알파 t 0.98로 통계적으로 확정되지는 않았습니다.**

> 포트폴리오용 개인 분석입니다. 실제 주문·매매 코드는 없으며 투자 권유가 아닙니다.

## 기준 B (문헌 기반)
- 3년 순이익 연평균 성장률 20~50%
- 0 < PEG < 1.0, PER < 40
- 부채비율 < 80%
- 재고 증가율 < 매출 증가율
- 연간 재무는 다음 해 4월부터 사용 (미래정보 차단)

## 핵심 결과

| 항목 | 결과 |
|---|---|
| 기준 B (2017-04~2026-10) | 연 8.57% vs 전 종목 동일가중 6.10% |
| 월간 알파 t / 무작위 대조 백분위 | 0.98 / 83.6% |
| 강건성 | 비용 5배·시작일 변경에도 우위 유지 |
| 수익 기여 | IT 업종 54% |
| 기준 A (기존 7조건) | 연 7.52%, 상위 5종목 기여 91% → 빼면 0.76%, 알파 t 0.78 |
| 운용 규칙: 눌림 대기 진입 | 모든 조합 손실 |
| 운용 규칙: PEG 비중 | 무작위 비중 대조 p 0.198 (차이 없음) |

## 실행 방법
Spyder에서 `피터린치의_전략.py`를 `#%%` 셀 단위로 실행합니다(conda 환경 `ta_env`, MySQL `stock_db`). DB 비밀번호는 환경변수로 넣고 코드에 쓰지 않습니다.

## 한계·생존편향 주의
- 상장폐지 종목을 포함했지만 2015년 이전 상장폐지 종목의 재무는 DART에 없어 빠져 있습니다.
- 성과가 IT 업종과 소수 종목에 몰려 있어, 다른 구간에서 같은 결과가 나온다는 보장이 없습니다.
