# 🧮 2자산 스텝다운 ELS 몬테카를로 평가

**KOSPI200·S&P500 기초 3년 만기 스텝다운 ELS를 자산평가회사의 평가 절차(발행정보 확인 → 시장데이터 수집 → 파라미터 산출 → 가치평가 → 가격검증)대로 직접 평가했습니다. 기본 시나리오 공정 쿠폰은 연 8.07%이고, 최근 1년 변동성을 넣으면 연 36.77%로 올라 변동성 입력이 가격을 가장 크게 흔든다는 것을 확인했습니다.**

> 포트폴리오용 개인 분석입니다. 가상의 예시 상품이며 실제 발행 상품의 가격이나 투자 권유가 아닙니다.

## 상품 (가상의 예시)

| 항목 | 조건 |
|---|---|
| 기초자산 | KOSPI200, S&P500 (원화 지급 = 콴토) |
| 만기 / 평가 | 3년 / 6개월마다 조기상환 평가 |
| 조기상환 배리어 | 90 - 90 - 85 - 85 - 80 - 75% (낮은 쪽 지수 기준) |
| 낙인 | 50%, 일별 종가 관찰 |
| 만기 미상환 시 | 낙인 없으면 원금 + 3년 쿠폰, 낙인 있고 75% 미만이면 낮은 쪽 성과만큼 지급 |

## 핵심 결과 (평가 기준일 2026-10-27)

| | 기본: 2014년 이후 변동성 | 스트레스: 최근 1년 변동성 |
|---|---:|---:|
| 변동성 KOSPI200 / S&P500 | 24.2% / 17.5% | 60.6% / 12.7% |
| 상관 (주간) | 0.53 | 0.37 |
| **공정 쿠폰 (연)** | **8.07%** | **36.77%** |
| 6개월 조기상환 확률 | 65.4% | 50.0% |
| 낙인 확률 | 10.7% | 65.0% |
| 원금손실 확률 / 손실 시 평균 손실 | 6.1% / 51% | 26.5% / 71% |

- **엔진 검증:** 같은 경로 생성기로 계산한 두 지수의 선도가격과 3년 ATM 콜옵션이 Black-Scholes 해석해와 표준오차 안에서 일치(KOSPI200 콜 0.4021 vs 0.4027 ± 0.0037). 40만 개 경로에서 가격 표준오차 0.023%p.
- **민감도 (기본):** 두 지수 변동성 +1%p → 가격 −0.63%, KOSPI200 +1% → +0.185%, 상관 +0.05 → +0.007%(이 구조에서는 작음).
- **상관 산출:** 한·미 장 마감 시각 차이로 일간 수익률 상관(0.15)이 실제보다 낮게 나와 주간 수익률(0.37)로 산출.
- **과거 실제 경로:** 2014-08 ~ 2023-10 매 거래일 발행 가정 2,271개 → 6개월 조기상환 85.8%, 원금손실 0건. 모형의 위험중립 확률(65.4%, 6.1%)과 다른 이유를 보고서에 정리.

자세한 내용은 보고서 `ELS_몬테카를로_평가_보고서.docx`(5쪽)를 보세요.

## 모형

- 위험중립 상관 GBM. KOSPI200 drift = r_KRW − q, S&P500 drift = r_USD − q − ρ(SPX, 원/달러)·σ_SPX·σ_FX (콴토), 할인은 원화 금리.
- 일별 756스텝, 경로 20만 개, 대조변수. 표준오차는 대조변수 쌍 단위로 계산.
- payoff가 쿠폰에 선형(P + c·Y)이라 공정 쿠폰을 시뮬레이션 1회로 산출: c* = (1 − E[DF·P]) / E[DF·Y].
- 민감도는 같은 난수로 입력만 바꿔 재평가(common random numbers).

## 실행 방법

```bash
pip install numpy scipy pandas matplotlib yfinance requests python-docx
python data.py          # 시장데이터 → data/ (저장소에는 올리지 않음)
python run.py           # 검증·평가·민감도·과거 경로 → results/ (약 4분)
python build_report.py  # 보고서 docx (Windows Word가 있으면 pdf도)
```

## 파일 구성

| 파일 | 내용 |
|---|---|
| `core.py` | 몬테카를로 엔진(상관 GBM, 대조변수, 콴토), 공정 쿠폰, 해석해 검증 |
| `data.py` | 시장데이터 수집 |
| `run.py` | 파라미터 산출 → 엔진 검증 → 수렴 → 민감도 → 과거 경로 |
| `build_report.py` | 보고서 생성 |
| `results/` | `results.json`, 그림(수렴·민감도·상환 분포·지급 구조·표본 경로) |
