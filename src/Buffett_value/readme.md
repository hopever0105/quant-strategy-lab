## 🎯 한눈에 보기

버핏이 숫자로 못 박은 규칙은 없어서 **모든 기준값은 분석자가 정한 가정**입니다.

| | 정기(A) | 신호(B) | 벤치마크 |
|---|---:|---:|---:|
| 변형 버전 CAGR (8.5년) | 1.1% | 2.3% | 5.1% |
| 실제 버전 CAGR (3.5년) | 5.0% | 3.1% | 3.8% |

- 변형 버전은 ROE·FCF 수익률 하한을 바꾼 9가지 조합 모두 벤치마크에 못 미쳤습니다.
- 2025년 이전에는 두 버전 모두 벤치마크에 뒤졌고, 앞선 구간은 2025~2026년뿐이었습니다.
- ROE 하한을 15%로 올리자 수익률이 오히려 크게 낮아졌습니다. 통과 종목이 줄어 집중도가 높아진 영향으로 보이지만 종목별 기여도는 분해하지 않았습니다.
- 현재(2026-10-16) 모든 조건을 통과한 종목은 실제 버전 3개, 변형 버전 7개입니다.

## 📐 기준 (9가지, 값은 모두 분석자 설정)

| 기준 | 구현 |
|---|---|
| ROE | 평균 12% 이상, 어느 해도 8% 아래로 내려가지 않음 |
| 현금 창출 | 자유현금흐름(영업현금흐름 − 설비투자)이 평가 기간 내내 흑자 |
| 이익의 질 | FCF 합계 / 순이익 합계 ≥ 0.7 |
| 이익 성장 | 순이익 연평균 증가율 ≥ 7% (처음·끝 2년 평균 비교) |
| 영업이익률 | 평균 10% 이상, 어느 해도 5% 아래로 내려가지 않음 |
| 부채 | 부채비율 ≤ 100% |
| 유동비율 | ≥ 1.5 |
| 가격 | 평균 FCF / 시가총액 ≥ 5% (PBR 상한은 쓰지 않음) |
| 규모 | 매출 ≥ 500억 원 |

### 🔀 두 가지 버전

| 버전 | 요구 재무 기간 | 백테스트 |
|---|---|---|
| 실제 (`strict`) | 최근 10년 | 2023-04부터 3.5년, 리밸런싱 4회, 평균 보유 5종목 |

## 🧪 백테스트 방식

| 구분 | 내용 |
|---|---|
| 정기(A) | 매년 4월 1일 이후 첫 거래일에 통과 종목을 동일가중으로 매수, 1년 보유 |
| 신호(B) | 재무 조건 통과 종목이 매수 상한가(시가총액 ≤ 평균 FCF / 5%) 아래로 내려온 날 매수, 다음 리밸런싱까지 보유 (목표 수익 매도 없음) |
| 벤치마크 | 전종목 동일가중 (코스피 지수가 아님) |
| 비용 | 왕복 0.3% |
| 재무 시차 | 결산 후 90일 뒤에 재무를 알 수 있다고 가정 |

## 🚀 실행 방법

```bash
conda activate ta_env
```

1. `kr_collect_core.py` → `kr_dart_long.py` → `kr_delisted.py` 순서로 실행해 MySQL(`stock_db`)에 데이터를 넣습니다. 이미 데이터가 있으면 건너뜁니다.

## ⚠️ 한계

- 기준값이 전부 분석자 설정입니다.
- 평균 보유 종목이 5~8개로 적어 종목 한두 개의 영향이 큽니다.
- FCF는 영업현금흐름에서 유형자산 취득만 뺀 값이고, 설비투자 계정이 없는 종목(금융업 등)은 평가에서 빠집니다.
- 연결 기준(비지배지분 포함)이라 지주회사류는 FCF 수익률이 부풀 수 있습니다.
- 시가총액은 현재 주식수 × 과거 수정주가로 근사했고, 12월 결산 법인만 분석했습니다.
- 업종 분포와 종목별 수익률 기여도는 분석하지 않았습니다.
