\# 버핏식 우량주 기준의 한국 시장 적용



워런 버핏의 투자 방식(높은 자기자본이익률, 꾸준한 현금 창출, 낮은 부채, 합리적인 가격)을 숫자 기준으로 옮겨 한국 상장 종목에 적용하고 백테스트했다. 버핏이 숫자로 못 박은 규칙은 없어서 모든 기준값은 분석자가 정한 가정이다. 전체 분석은 \[보고서](../../reports/buffett\_report.pdf)에 있다.



\## 분석 대상

\- 현재 상장 보통주 2,532종목 + 2015년 이후 상장폐지 424종목

\- 이 중 연간 재무(2013\~2025 회계연도, OpenDART)를 확보한 2,320종목

\- 주가: 네이버 수정주가, 2015-01-02 \~ 2026-10-16



\## 기준 (9가지, 값은 모두 분석자 설정)

| 기준 | 구현 |

|---|---|

| ROE | 평균 12% 이상, 어느 해도 8% 아래로 내려가지 않음 |

| 현금 창출 | 자유현금흐름(영업현금흐름 − 설비투자)이 평가 기간 내내 흑자 |

| 이익의 질 | FCF 합계 / 순이익 합계 ≥ 0.7 |

| 이익 성장 | 순이익 연평균 증가율 ≥ 7% (처음·끝 2년 평균 비교) |

| 영업이익률 | 평균 10% 이상, 어느 해도 5% 아래로 내려가지 않음 |

| 부채 | 부채비율 ≤ 100% |

| 유동비율 | ≥ 1.5 |

| 가격 | 평균 FCF / 시가총액 ≥ 5% (PBR 상한은 쓰지 않음) |

| 규모 | 매출 ≥ 500억원 |



\## 두 가지 버전

\- \*\*실제 버전\*\*: 최근 10년 재무를 요구. 백테스트 2023-04부터 3.5년, 리밸런싱 4회, 평균 보유 5종목

\- \*\*변형 버전\*\*: 일정 수 이상의 종목을 고르고 더 긴 기간을 검증하려고 5년으로 줄임. 2018-04부터 8.5년, 리밸런싱 9회, 평균 보유 8.2종목



코드 안의 `strict`는 실제 버전, `real`은 변형 버전이다.



\## 백테스트 방식

\- 정기(A): 매년 4월 1일 이후 첫 거래일에 통과 종목을 동일가중으로 사서 1년 보유

\- 신호(B): 재무 조건 통과 종목이 매수 상한가(시가총액 ≤ 평균 FCF / 5%) 아래로 내려온 날 매수, 다음 리밸런싱까지 보유 (목표 수익 매도 없음)

\- 벤치마크: 전종목 동일가중 (코스피 지수가 아님)

\- 거래비용 0.3% 왕복, 결산 후 90일 뒤에 재무를 알 수 있다고 가정



\## 결과

| | 정기(A) | 신호(B) | 벤치마크 |

|---|---|---|---|

| 변형 버전 CAGR (8.5년) | 1.1% | 2.3% | 5.1% |

| 실제 버전 CAGR (3.5년) | 5.0% | 3.1% | 3.8% |



\- 변형 버전은 ROE·FCF 수익률 하한을 바꾼 9가지 조합 모두 벤치마크에 못 미쳤다.

\- 2025년 이전에는 두 버전 모두 벤치마크에 뒤졌고, 앞선 구간은 2025\~2026년뿐이었다.

\- ROE 하한을 15%로 올리자 수익률이 오히려 크게 낮아졌다. 통과 종목이 줄어 집중도가 높아진 영향으로 보이지만 종목별 기여도는 분해하지 않았다.

\- 현재(2026-10-16) 모든 조건을 통과한 종목: 실제 버전 3개, 변형 버전 7개

\## 한계

\- 기준값이 전부 분석자 설정이다.

\- 평균 보유 종목이 5\~8개로 적어 종목 한두 개의 영향이 크다.

\- FCF는 영업현금흐름에서 유형자산 취득만 뺀 값이고, 설비투자 계정이 없는 종목(금융업 등)은 평가에서 빠진다.

\- 연결 기준(비지배지분 포함)이라 지주회사류는 FCF 수익률이 부풀 수 있다.

\- 시가총액은 현재 주식수 × 과거 수정주가로 근사했다. 12월 결산 법인만 분석했다.

\- 업종 분포와 종목별 수익률 기여도는 분석하지 않았다.



\## 실행

먼저 `data\_pipeline/`의 `kr\_collect\_core.py` → `kr\_dart\_long.py` → `kr\_delisted.py`를 순서대로 실행해 MySQL(`stock\_db`)에 데이터를 넣는다. 이미 데이터가 있으면 건너뛴다. 그다음 `buffett\_screen\_backtest.py`를 `#%%` 셀 단위로 실행한다 (Spyder, conda 환경 `ta\_env`).



DB 비밀번호는 환경변수 `DB\_PW`로 읽는다. 코드에 직접 쓰지 않는다.
