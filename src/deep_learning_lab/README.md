# 🧠 딥러닝 전략 4종 검증

**MLP·CNN·LSTM·오토인코더를 실제 투자 문제 4개에 적용하고, 같은 입력의 단순 모델과 비교해 검증했습니다. 살아남은 것은 '미국 밤사이 반도체 정보 → 국내 반도체 ETF 장중 매매' 하나입니다. 로지스틱 확률 상위 20% 날만 사면 2014~2026 KODEX 반도체 1회 +0.27%(t 4.12, 782회), 샤프 0.94(보유 0.56), 최대 낙폭 −19%(보유 −55%)였고, 학습에 쓰지 않은 TIGER 반도체에서도 t 4.16으로 같은 결과가 나왔습니다. 살아남은 모델은 LSTM이 아니라 로지스틱이었습니다.**

> 포트폴리오용 개인 분석입니다. 실제 주문·매매 코드는 없으며 투자 권유가 아닙니다.

## 전략과 판정

| 전략 | 모델 | 판정 | 핵심 숫자 |
|---|---|---|---|
| 한미 시차 → 반도체 ETF 장중 매수 | LSTM vs 로지스틱 | ✅ 살아남음 | KODEX 1회 +0.27%(t 4.12), TIGER(학습 안 씀) t 4.16, 손익분기 왕복 비용 0.27% |
| ETF 10개 자산배분 | MLP + 모멘텀 앙상블 | 🟡 보조 | 2012~ 샤프 0.80 vs 모멘텀 0.70, 2006~2011엔 0.40 vs 0.43 |
| 자산 히트맵 시장 타이밍·급락 위험 | CNN | ❌ 버림 | 급락 AUC 0.51 < 모델 없는 20일 변동성 0.70 |
| 잠재공간 페어 트레이딩 | 오토인코더 | ❌ 버림(공적분 필터만 남김) | 공적분 짝만 샤프 −0.07 → 0.47, 연 1~2.5% |

## 반도체 ETF 장중 전략 검증

| 검증 | 결과 |
|---|---|
| 비용 0.05 → 0.15 → 0.20% | 샤프 0.94 → 0.52 → 0.31 (상위 10% 규칙은 0.20%에서도 0.57) |
| 학습에 안 쓴 상품 (TIGER 반도체) | 1회 +0.28%, t 4.16, 샤프 0.97 |
| 2024년까지 한 번만 학습 → 2025~ | KODEX 1회 +0.74%(t 3.01), TIGER +0.82%(t 3.13) |
| 2020·2026 제외 | 샤프 0.52, 상위 2개 해가 로그 수익의 65% |
| 변동성 구간 | 높은 3분의 1에서만 효과(1회 +0.60%, t 4.26) |
| 여러 번 시험 보정 | t > 3.3 통과 4개 규칙(KODEX·TIGER × 상위 20%·10%) |
| 가장 나은 운용 | 확률 비례 금액: 샤프 1.00, 최대 낙폭 −13.4%, 13년 중 11년 플러스 |

미국 반도체(SOXX)가 크게 오른 다음 날 국내 반도체는 시가가 높게 뜨고 장중에 되돌립니다(SK하이닉스 5분위 장중 −0.29%, t −3.3). 미국 정보가 시가에 과하게 반영된다는 관찰이 전략의 출발점입니다.

## 실행 방법
Spyder(conda `ta_env`, TensorFlow 2.x)에서 `#%%` 셀 단위로 실행합니다. 맨 위 [1] 환경 설정 셀 → 원하는 [추가 전략] 셀. DB(MySQL `stock_db`) 접속 정보는 `.env`(환경변수 `QUANT_ENV_PATH`로 경로 지정)에서 읽고 코드에 쓰지 않습니다. 보고서는 `python build_report.py`.

## 한계
- 시가 동시호가에 그대로 체결된다고 가정했습니다. 실제 시가 체결 비용은 확인하지 못해 비용 0.15·0.20% 결과를 함께 봅니다.
- 효과가 변동성 큰 해(2020·2026)에 몰려 있습니다.
- 국내 종목은 현재 상장 종목 위주(생존 편향), 업종은 현재 시점 하나만 씁니다.
- 오토인코더 재무 특성 실험은 재무 자료가 2022년 이후뿐이라 8개 기간으로만 봤습니다(자료 확장 후 재검증 예정).
