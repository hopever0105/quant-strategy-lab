# 추가 전략 2: 10개 자산 수익률 히트맵 CNN으로 SPY 시장 타이밍

- 실행 시각: 2026-11-21 10:48
- TensorFlow 사용: True (False면 신경망 대신 대체 모델로 낸 결과)

## 한눈에

- 표본 밖 AUC: CNN 0.487, 로지스틱 0.505 (0.5 = 동전 던지기)
- 샤프: CNN 신호 0.38 / 로지스틱 0.25 / 200일선 1.00 / SPY 0.93
- MDD: CNN 신호 -33.1% vs SPY -33.7%, SPY를 이긴 해 2/15
- 가렸을 때 가장 나빠진 부분: 6~20일 전 전부 (AUC -0.017)

## 설정

- 입력: 10개 ETF(SPY, IEV, EWJ, EEM, TLT, IEF, IYR, RWX, GLD, DBC) 최근 20일 표준화 수익률 = 20x10 그림 한 장
- 정답: SPY 다음 5거래일 수익률 > 0, 학습과 예측 사이 5일 비움
- 모델: Conv 16 - Pool(2,1) - Conv 32 - Pool(2,2) - Dense 32 - Dropout 0.3 - sigmoid, 최대 15회 학습·조기 종료
- 워크포워드: 2012년부터 매년 재학습, 표본 밖 3716일 (2012-01-03 ~ 2026-10-13)
- 매매: 예측 확률 > 학습 구간 평균 확률이면 다음 날 SPY 보유, 아니면 현금. 한쪽 비용 0.05%
