- 실행 시각: 2026-11-21 10:50
- TensorFlow 사용: True (False면 신경망 대신 대체 모델로 낸 결과)

## 한눈에

- 급락 위험 AUC: CNN 전체 0.508 / CNN 고른 자산 0.555 / 로지스틱 0.580 / SPY 20일 변동성(모델 없음) 0.697
- CNN '위험 높음' 날 실제 급락 비율 11.4% vs 나머지 날 7.8%
- 샤프: SPY 보유 0.93 / 200일선 위에서만 보유 1.00 / CNN 위험 높으면 빼기 0.64 / 200일선 위 + CNN 위험 낮을 때만 0.88 / 200일선 위 + 고른자산 CNN 위험 낮을 때만 0.65 / 200일선 위 + 로지스틱 위험 낮을 때만 0.73 / 200일선 위 + 변동성 낮을 때만(모델 없음) 0.97 / 200일선 위 또는 CNN 위험 낮음(빨리 재진입) 0.75
- 200일선만 대비 '200일선 + CNN' 샤프 차이 -0.12, '200일선 + 변동성(모델 없음)' 차이 -0.03 (CNN이 단순 변동성보다 나은지)

## 설정

- 입력: 추가 전략 2와 같은 20일 x 10자산 표준화 수익률 그림
- 정답: 다음 5거래일 안에 SPY 종가가 오늘보다 -3% 이상 낮은 날이 있으면 1 (급락 위험)
- '위험 높음' = 예측확률이 학습 구간 확률의 80% 분위 초과. 급락이 드물어 학습 때 클래스 가중치 사용
- 고른 자산 CNN: 매년 학습 구간 마지막 15%에서 자산을 하나씩 가려 AUC가 많이 떨어지는 5개만 남겨 다시 학습
- 비교: 모델 없는 SPY 20일 변동성 (높으면 위험), 200일선, SPY 보유. 한쪽 비용 0.05%
