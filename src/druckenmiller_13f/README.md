# 🎯 드러켄밀러 13F 분석 — 그가 산 종목의 공통점에서 수주잔고 신호까지

스탠리 드러켄밀러(Duquesne Family Office)의 13F 보고서 62건(2011년 4분기~2026년 2분기)으로 다음을 확인했습니다.

1. 그가 산 종목의 공통 특징
2. 그 선택이 실력인지
3. 따라 사거나 규칙으로 옮기면 돈이 되는지
4. 숫자로 남는 재료가 무엇인지

실제 매매는 하지 않는 분석용 저장소입니다.

📄 보고서: [드러켄밀러_13F_종합보고서.pdf](드러켄밀러_13F_종합보고서.pdf) (20쪽, [Word](드러켄밀러_13F_종합보고서.docx))

## 핵심 결과

| 질문 | 결과 |
|---|---|
| 무엇을 샀나 | 변동성·베타가 높은 고성장주를 샀습니다(S&P500 안 백분위: 변동성 72, 베타 67). 이익률·밸류에이션은 S&P500보다 낮고, 보유 기간은 중앙값 1분기입니다. |
| 실력인가 | 실력은 비중 3% 이상의 확신 매수에만 보입니다. 같은 업종에서 특징이 가장 닮은 5종목보다 6개월 뒤 61%가 나았습니다(분기 t 3.4). 작은 매수는 51%로 차이가 없습니다. |
| 무엇이 그 차이를 만드나 | 공개 숫자로는 설명되지 않습니다. 18개월 뒤를 보는 판단, 하락장에서 크게 거는 결단(2022년 4분기 엔비디아·메타·버티브), 맞으면 키우고 틀리면 자르는 운용입니다. |
| 따라 사기 (13F 공시일) | 2022년 이후에만 알파가 있습니다(t 2.3~2.5). 2012~2021년에는 0입니다. |
| 특징을 규칙으로 | 무작위로 고른 종목과 비교한 백분위가 학습 99, 검증 99, 테스트 61입니다. 테스트 구간에서 실패했습니다. |
| 조합 750개·머신러닝 | 학습 구간 1등이 표본 밖에서는 중간 이하였습니다. 미국 ML의 IC는 −0.004입니다. |
| 보조 재료 | 유동성 점수와 손절은 무효, 다른 펀드 동시 매수는 약함, 공시 단어 테마는 보조로 쓸 정도입니다. |
| **수주잔고 증가율 − 매출 증가율** | **미국 IC 0.041(t 4.05), 한국 수주 업종 IC 0.087(t 2.77, 2025년 제외 t 2.60)** → 별도 전략 [order_backlog](../order_backlog) |

## 실행 방법

1. 환경변수를 설정합니다: `DART_KEY`(OpenDART). SEC·야후·OpenFIGI는 키가 필요 없습니다.
2. 수집 → 특징 → 검증 순서로 위 표의 파일을 실행합니다(Spyder F5 또는 `python 파일명.py`).
3. 마지막으로 `python build_report_full.py 최종`을 실행합니다.

수집 결과는 `quant/cache/druck13f/`에 저장되며, 저장소에는 넣지 않았습니다. 중간에 끊겨도 이어받기가 됩니다.

## 한계와 주의

- 13F는 분기말 하루의 미국 상장 주식·옵션 명단입니다. 분기 안의 매매와 채권·통화·선물·공매도는 보이지 않습니다.
- 생존편향: 비교군인 S&P500 중 이후 상장폐지돼 시세가 없는 종목이 빠졌습니다(초기 기간에 많음). 그래서 학습 구간 숫자가 좋게 나왔을 수 있습니다.
- 미래정보 차단: 재무와 수주잔고는 분기말 이전에 공시된 값만 썼습니다. 한국 연간 매출은 다음 해 4월부터 썼습니다.
- 미국 수주잔고는 2019년부터 공시돼 학습 구간이 없습니다. 한국은 원문 표를 규칙으로 읽은 값이라 회사마다 잡음이 있습니다.
- 강연·인터뷰 내용은 공개 보도와 2차 정리본에 근거합니다(출처는 보고서에 있습니다).
