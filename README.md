# Quant-strategy-lab

국내 주식 매매 전략을 같은 기준(다음날 시가 진입, 거래비용 반영, 무작위 진입 대조)으로 검증하는 프로젝트입니다. "신호가 보인다"가 아니라 "비용을 빼고도 우연보다 나은가"를 확인하는 것이 목적입니다.

## 한눈에 보기

- **질문**: 널리 쓰이는 기술적 전략들이 비용을 뺀 뒤에도 무작위 진입보다 나은가?
- **데이터**: KRX 일봉 (pykrx), 코스피/코스닥
- **검증 방식**: 다음날 시가 진입, 수수료·세금·슬리피지 반영, 무작위 진입 대조, 기간 분할

## 하이킨아시 신호 규칙

1. 도지(몸통이 작은 봉)캔들이 1개 이상 이어진 뒤
2. 하이킨아시 양봉이 나오고, 아래꼬리가 거의 없으며 윗꼬리가 길어야 하고
3. 신호 봉의 거래량이 직전 도지 봉보다 크며
4. 도지 직전 구간의 음봉 비율이 65% 이상일 것 (하락 추세)

손절가는 도지 구간 최저가의 0.5% 아래, 익절가는 손익비 1:2로 계산합니다.
